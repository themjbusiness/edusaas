## 1. Executive Summary & Release Goals

EduSaas v1.0 and v1.1 established the core absence-to-clearance loop, progressive web app (PWA) design system, college admin console, multi-subject support, and Urdu interface.

Version **v1.2** delivers the **Pilot College Term Capabilities**. It transitions EduSaas from a working demonstration into an enterprise B2B product ready to pilot at FBISE colleges with real teachers, principals, and hundreds of daily absent students.

### The 5 Features in v1.2:
1. **F7: Teacher Content Review Screen**: An interactive curation screen where subject teachers listen to pre-generated lecture segments, edit scripts, review/edit MCQs, and publish or reject lessons before students see them.
2. **F9: Mastery Remediation Paths**: Adaptive catch-up for students scoring < 80% on clearance quizzes. Replays targeted lecture sections for missed questions, issues fresh question sets, enforces attempt cooldowns, and escalates to the teacher after 3 failures.
3. **F10: Principal Analytics Dashboard**: High-level reporting for college principals: college-wide absence rates, clearance percentages, median time-to-clear, class-by-class comparison, and CSV/PDF executive exports.
4. **F11: Teacher Weekly At-Risk Digest**: Automated notification and screen highlighting students with recurring absences, repeated quiz failures, or unresolved clearances.
5. **F8: Full FBISE Syllabus Pipeline & Tracker**: Scaled Content Factory production tracker for all units of 11th grade Physics, Chemistry, Biology, and Mathematics.

## 3. Data Model Changes

### 3.1 Content Review Status (F7 & F8)
Add review states and teacher attribution to `Lesson`:
```python
class Lesson(models.Model):
    DRAFT = "draft"
    IN_REVIEW = "in_review"
    APPROVED = "approved"
    REJECTED = "rejected"
    STATUS_CHOICES = [
        (DRAFT, "Draft"),
        (IN_REVIEW, "In Review"),
        (APPROVED, "Approved"),
        (REJECTED, "Rejected"),
    ]
    # New fields
    review_status = models.CharField(max_length=20, choices=STATUS_CHOICES, default=APPROVED)
    reviewed_by = models.ForeignKey(User, null=True, blank=True, on_delete=models.SET_NULL, related_name="reviewed_lessons")
    reviewed_at = models.DateTimeField(null=True, blank=True)
    review_notes = models.TextField(blank=True)
```

### 3.2 Quiz Mastery & Attempt Tracking (F9)
Extend `QuizAttempt` to record question-level outcomes and remediation linkage:
```python
class QuizAttempt(models.Model):
    # Existing: id, student, lesson, score, passed, created_at
    # New fields:
    attempt_number = models.PositiveSmallIntegerField(default=1)
    missed_sections = models.JSONField(default=list)  # list of section IDs missed
    escalated_to_teacher = models.BooleanField(default=False)
    cooldown_until = models.DateTimeField(null=True, blank=True)
```

### 3.3 Teacher Override & Notes (F9 & F11)
Enhance `Clearance`:
```python
class Clearance(models.Model):
    # Existing: id, student, attendance, cleared_at, status ("cleared", "override")
    override_reason = models.CharField(max_length=255, blank=True)
    override_by = models.ForeignKey(User, null=True, blank=True, on_delete=models.SET_NULL, related_name="clearance_overrides")
```

## 4. API Endpoints Specification

### 4.1 F7: Teacher Content Review Endpoints (`/api/review/`)
- `GET /api/review/lessons?subject=&status=`: List lessons available for review.
- `GET /api/review/lessons/<lesson_id>`: Detailed breakdown with audio segment timestamps, transcript text, and MCQ pool.
- `PUT /api/review/lessons/<lesson_id>`: Teacher edits transcript text or modifies quiz questions.
- `POST /api/review/lessons/<lesson_id>/decide`: `{ "action": "approve" | "reject", "notes": "..." }`.

### 4.2 F9: Mastery Path Endpoints (`/api/student/`)
- `GET /api/student/lessons/<lesson_id>/remediation`: Returns weak sections to re-listen after a failed attempt (<80%).
- `POST /api/student/lessons/<lesson_id>/quiz/retake`: Verifies cooldown expiration, pulls unattempted or refreshed questions, records attempt number.
- `POST /api/teacher/clearances/<clearance_id>/override`: Allows teacher to manually clear an escalated student (after 3 failures) with an audited reason.

### 4.3 F10: Principal Dashboard Endpoints (`/api/principal/`)
- `GET /api/principal/overview?days=30`: Total absences, clearance rate, median hours to clearance, active enrollment.
- `GET /api/principal/breakdown?by=class|teacher`: Comparative table showing clearance performance per section and teacher.
- `GET /api/principal/export?format=csv`: Downloadable attendance-clearance audit log for governors and board inspections.

### 4.4 F11: Teacher Weekly At-Risk Endpoints (`/api/teacher/`)
- `GET /api/teacher/at-risk`: Students with &ge; 2 uncleared absences or 3 failed quiz attempts.
- `POST /api/teacher/at-risk/<student_id>/nudge`: Sends a reminder alert (push/WhatsApp) to parent.

## 5. Screen Layouts & UI Specifications

All screens follow the FBISE design tokens established in F1, responsive from 360px up to 1440px with full dark mode support:

| Screen | Route | Key Components |
|---|---|---|
| **Content Reviewer** | `/review/:lessonId` | Audio waveform/segment player, synchronized transcript editor, interactive MCQ card editor, Approve/Reject floating bottom bar. |
| **Remediation Player** | `/lessons/:id/remedy` | "Focus Review" mode highlighting only missed sections, retake quiz launcher, attempt counter pill (e.g. "Attempt 2 of 3"). |
| **Escalation Banner** | In `/lessons/:id` & `/teacher` | Warning for 3 failed attempts: "Clearance escalated to teacher Mr. Tariq". Teacher one-tap override modal. |
| **Principal Console** | `/principal` | Executive KPI metric cards, class performance bar charts, clearance velocity histogram, export button. |
| **At-Risk Class Digest** | `/teacher/at-risk` | Filter chips ("Repeated Absences", "Failed Quiz", "Pending Override"), student cards with emergency parent contact link. |
